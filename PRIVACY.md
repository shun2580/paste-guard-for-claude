# Privacy Policy — Paste Guard for Claude

Last updated: 2026-08-03

## English

Paste Guard for Claude does not collect, store, transmit, or share any data. Period.

- **No data collection.** The extension has no analytics, no telemetry, and no logging beyond the browser's local developer console.
- **No network activity.** The extension contains no code capable of making network requests. You can verify this in the source code — it is a single ~90-line script.
- **No permissions.** The extension requests zero Chrome permissions. It does not use the clipboard-read permission; it only reads the contents of paste events that you yourself trigger inside the claude.ai message editor, at the moment you trigger them. That content goes directly into the claude.ai editor and nowhere else.
- **Scope.** The extension runs only on https://claude.ai and interacts only with the message input editor.

Since no data is collected, there is nothing to sell, share, retain, or delete.

## 日本語

Paste Guard for Claude は、いかなるデータも収集・保存・送信・共有しません。

- **データ収集なし。** アナリティクス、テレメトリ、ログ送信は一切ありません(ブラウザのローカルな開発者コンソールへの警告出力を除く)。
- **通信なし。** 本拡張には通信を行うコードが存在しません。ソースコードは約90行の単一スクリプトで、全文を公開しています。
- **権限なし。** Chrome の権限を一切要求しません。クリップボード読み取り権限も使用せず、あなた自身が claude.ai のメッセージ入力欄で行ったペースト操作のイベント内容を、その瞬間にのみ読み取ります。その内容は claude.ai の入力欄に挿入される以外のどこにも渡りません。
- **動作範囲。** 本拡張は https://claude.ai 上でのみ動作し、メッセージ入力欄に対してのみ作用します。

データを収集しないため、販売・共有・保持・削除の対象となるデータそのものが存在しません。
